# Plainwise

**「分かった」で終わらせず、「なるほど、そういうことか」へ。**

Plainwise は、聞き手が**ものの見方を変える説明**を目指す日本語Agent Skillです。上岡龍太郎氏の説明術から着想を得ていますが、口調や発言を模倣するものではありません。

## 説明の作り方

1. 誰でも想像できる場面から、聞き手に自然に語りかける
2. **同じ条件で二つの状態を比較する**
3. 予想と結果の食い違いを、短い問いで示す
4. なぜ違うのか、具体的な数値や仕組みでつなぐ
5. **最初と違う物差し**を聞き手に残す

関西弁や決め台詞は使いません。正確さを犠牲にした意外性も作りません。

## 実際の出力例

**質問：原価700円の商品を1,000円で100個販売。800円に値下げして同じ粗利益を得るには？**

> 値下げ前は、1個あたりの粗利益が「1000円−700円＝300円」です。100個売ると、粗利益は3万円になります。
>
> 値下げ後は、1個あたり「800円−700円＝100円」。同じ3万円を得るには、
>
> **3万円÷100円＝300個**
>
> 売る必要があります。価格は20％の値下げでも、1個あたりの粗利益は300円から100円へ3分の1になるため、販売数は3倍必要です。

※現行版のスキル指示を適用して生成した回答です。費用は商品原価のみで比較しています。

## インストール

```bash
npx skills add tamutamu/plainwise
```

「Plainwiseを使って、なぜ会議で全員が賛成しても仕事が進まないのか説明してください」のように依頼します。
