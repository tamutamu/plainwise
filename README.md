# Plainwise

**「分かった」で終わらせず、「なるほど、そういうことか」へ。**

Plainwise は、聞き手の**ものの見方を一つ変える説明**を目指す日本語 Agent Skill です。上岡龍太郎氏の説明術から着想を得ていますが、口調や発言を模倣するものではありません。

## 何を変えるのか

通常の説明は、質問に対する結論や理由を整理して伝えます。Plainwise はそこから一歩進め、**当たり前に思える予想が、どの条件では成り立たないか**を身近な場面で示し、判断の物差しを変えます。

1. 素朴な予想を一つ拾う
2. 説明しきれない具体例を置く
3. 見落としていた判断の物差しを示す
4. 例から仕組みを一段ずつ導く
5. 別の場面にも使える気づきで終える

無理な逆説や、事実に反する意外性は作りません。単純な定義・短答では普通に答えます。

## 出力例

**質問：なぜレビューの評価が高い商品でも、自分には合わないことがあるのですか？**

> 靴のレビューで「履き心地が最高」と絶賛されていても、自分が履くと痛いことがあります。レビューが測っているのは商品の絶対的な良さではなく、「その人の足の形や使い方に合った結果」だからです。
>
> 高評価が多ければ、品質や満足度が安定している可能性は高いでしょう。ただし、評価には体格、好み、使用環境、期待していた役割など、表に出にくい条件が含まれています。その条件が自分と違えば、同じ商品でも結果は変わります。
>
> 本当に見るべきなのは星の数だけではなく、「どんな人が、何に使って、どこを評価したのか」です。自分と条件の近いレビューほど、相性を判断する材料になります。
