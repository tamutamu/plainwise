# 「なるほど！」を検証するためのベンチマーク

Plainwiseが普通のAIより**実際に読者の見方を変えるか**を確かめるためのテストです。従来の「例がある」「短い」「読みやすい」といった形式の採点では不十分です。

## 何を比較するか

同じモデル・推論設定・質問・長さの共通指示に対して、以下の3条件を独立セッションで実行します。

| 条件 | 追加する指示 |
| --- | --- |
| baseline | 共通指示だけ |
| strong_general_instruction | 「なるほど」と思わせるための十分に強い一般的な指示 |
| plainwise_candidate | 候補 `SKILL.md` 全文 |

質問は[事前に凍結した16問](./aha_holdout_v1.json)を使用し、各条件3回、**合計144回答**を生成する設計です。出力順序を固定シードで入れ替え、評価者には回答の出所を示しません。

## 実行

Python 3.10以上、認証済みのCodex CLIが必要です。

```bash
python evaluation/run_aha_benchmark.py --dry-run
python evaluation/run_aha_benchmark.py
python evaluation/make_blind_review.py
```

Codex CLIがPATHにないWindows環境では、`PLAINWISE_CODEX_CMD_JSON` に `["node.exeの絶対パス","codex.jsの絶対パス"]` のJSON文字列を設定できます。

生成結果は `evaluation/results/` に保存します。途切れたら同じコマンドで再開可能です。異なるモデルやスキルに切り替えた場合は、別の出力先を使用してください。

**生成時のエラーやツール使用は、黙って除外・再実行せずに記録して確認します。** 判定者が推測できるようなスキル名も回答本文に含めません。

## 採点

回答を実際に読んだ人に、次の観点を回答元が分からない状態で評価してもらいます。

| 観点 | 採点 |
| --- | --- |
| 事実・計算・因果が正確か | 0〜4 |
| 聞く前にはなかった**新しい気づき**があるか | 0〜4 |
| 何の思い込み・物差しが変わったか、自分の言葉で言えるか | 0〜4 |
| 別の場面でもその見方を使えそうか | 0〜4 |

評価者には**「何の見方が変わったか。なければ『なし』」**と自由記述してもらいます。この欄が埋められないなら、いくら文章が綺麗でもPlainwiseの目的は達していません。

正確さに重大な問題がある回答は、他項目の得点にかかわらず不合格にします。初学者への威圧や、ありもしない弱い反論の論破でも加点しません。

## 完成の判断

**強い一般指示にも勝てるか**が重要です。通常AIだけより良くても、適切な一般指示と同等なら独立したスキルの価値は示せません。

人間の読者による評価がまだない場合は、成果を「説明スタイルの変化」と呼び、**「『なるほど！』を生む効果を実証した」とは書きません。**

このファイルは評価の**実施手順**であり、現時点で144回答を生成・採点したという報告ではありません。過去の同一モデルによる匿名AI採点を、人間の理解度の証拠と混同しないでください。
